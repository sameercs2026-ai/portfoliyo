# Sameer — Data Analytics Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser.
3. Edit the content and links as described below.

## Personalize before publishing
Search the files for these placeholders:
- `your.email@example.com` — replace with your professional email.
- `href="#"` on the LinkedIn and GitHub social links — replace with your profile URLs.
- Project placeholder descriptions — replace with your real project names, summaries, GitHub links and live demos.
- Confirm the displayed CGPA (currently set to 8.2/10) and college name.
- Your supplied profile photo is stored at `assets/sameer-profile.jpeg`.
- Add a resume PDF and link it from the hero or contact area if you want a downloadable CV.

## Deploy free on Vercel
1. Create a GitHub repository and upload `index.html`, `style.css`, and `script.js`.
2. Sign in to Vercel with GitHub and choose **Add New → Project**.
3. Import the repository.
4. For a static site, leave the framework preset as **Other**; no build command is required.
5. Deploy. Vercel will provide your public URL.

No build tools or dependencies are required. Google Fonts are loaded from the web; system fallbacks are included.
